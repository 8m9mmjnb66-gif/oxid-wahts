OXID WHATS PWA
هذه نسخة ويب قابلة للإضافة إلى الشاشة الرئيسية للآيفون.
طريقة النشر من الآيفون:
1) ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة مثل Netlify أو GitHub Pages.
2) افتح رابط الموقع المنشور في Safari.
3) اضغط مشاركة ثم Add to Home Screen / إضافة إلى الشاشة الرئيسية.
4) اختر Add. ستظهر أيقونة OXID على الشاشة.

تنبيه: هذه واجهة تجريبية محلية. الرسائل لا تصل إلى أشخاص آخرين، ولا يوجد تسجيل دخول أو خادم أو ذكاء اصطناعي فعلي أو مشاركة مواقع فعلية بعد. تحتاج هذه الوظائف إلى Backend وقاعدة بيانات ومفاتيح API محفوظة على الخادم.
